# 考试运营增强设计

日期：2026-04-23

## 背景

当前考试主链路已经完成从出卷、发布、学生作答到老师批阅的最小闭环，但老师侧运营效率和学生侧异常恢复仍偏弱，主要缺口集中在三块：

1. 老师成绩列表缺少筛选与导出能力。
2. 主观题批阅只有单题查看与保存，缺少待批阅工作流。
3. 学生作答与老师批阅在请求失败、刷新重进等场景下恢复不足。

用户本轮已明确范围：

- 继续做 `成绩明细筛选/导出`
- 继续做 `更完整的批阅工作台`
- 继续做 `更完善的异常恢复`
- 暂缓 `更好的试卷题干富预览`

## 目标

在不重做现有考试主链路的前提下，增强老师侧考试运营能力与学生侧稳定性，使老师可以高效定位成绩与待批阅记录，学生在异常情况下可以继续作答。

## 设计范围

### 1. 成绩明细筛选与 CSV 导出

在老师考试详情页现有“考试统计/成绩列表”基础上补齐：

- 筛选项：
  - 作答状态：`全部 / 未开始 / 作答中 / 已交卷`
  - 批阅状态：`全部 / 待批阅 / 已批阅`
  - 关键词：按学生姓名 / 学号匹配
- 当前筛选结果 CSV 导出

后端设计：

- 扩展 `GET /api/v1/analytics/exam-overview`
  - 新增 query：`attempt_status`、`review_status`、`keyword`
  - 继续返回分页结果
- 新增 `GET /api/v1/analytics/exam-overview-export`
  - 使用与列表同一套筛选条件
  - 返回 `text/csv`

批阅状态定义：

- `待批阅`：存在主观题，且至少有一题仍处于人工待批阅状态
- `已批阅`：无主观题，或所有主观题已完成批阅

导出列首版固定为：

- 学生姓名
- 学号
- 班级
- 作答状态
- 批阅状态
- 客观题得分
- 主观题得分
- 总分
- 开始时间
- 交卷时间

### 2. 更完整的批阅工作台

老师现有“查看答卷”升级为带队列能力的批阅工作台，目标是减少老师在成绩列表和单题详情之间反复跳转。

前端补齐：

- 成绩列表增加“批阅状态”列与快捷入口
- 在答卷区增加：
  - 仅看待批阅题切换
  - 上一题 / 下一题
  - 待批阅数量、已批阅数量、总题数
  - 自动定位到首个待批阅主观题
  - 当前答卷内批阅完成提示
- 在成绩列表中，若学生整卷处于待批阅状态，文案优先突出“继续批阅”

后端维持单题保存接口不变，避免本轮引入批量事务接口，先让工作台围绕现有 `GET /api/v1/analytics/exam-attempt-review` 与 `PUT /api/v1/analytics/exam-attempt-question-review` 工作。

### 3. 更完善的异常恢复

#### 学生侧

- 开考失败：保留错误提示，不清空考试列表
- 保存答案失败：保留当前选择，允许重试，并提示失败原因
- 交卷失败：
  - 保持当前作答上下文不丢失
  - 支持再次交卷
- 刷新恢复：
  - 使用本地存储记录最近一次 `in_progress` 的 `exam_id` / `attempt_id`
  - 页面初始化时优先尝试恢复这条未完成答卷
  - 若服务端已无对应作答或状态已结束，则清理本地恢复信息

#### 老师侧

- 加载考试统计失败时保留已选考试详情，不清空整页上下文
- 批阅保存失败时保留当前输入，提示可重试
- 切换答卷失败时不覆盖当前已打开的答卷

## 架构影响

### 后端

- `internal/modules/analytics`
  - 扩展 `ExamOverviewQuery` / `ExamOverviewStudentItem`
  - 补充筛选查询、批阅状态计算与 CSV 导出
- `internal/modules/exam`
  - 不新增核心表
  - 复用现有 `GET /exam-attempts/:id` 做学生端恢复

### 前端

- `apps/user-web/src/teacher-exam-page.tsx`
  - 增加筛选栏、导出按钮、批阅队列状态
- `apps/user-web/src/student-exam-page.tsx`
  - 增加恢复逻辑、错误状态和重试动作
- `packages/api-sdk/src/client.ts`
  - 增加考试统计导出接口

## 不做内容

- 试卷题干富预览增强
- Excel 导出
- 批量批阅接口
- 离线答题与断网队列

## 测试策略

### 后端

- 考试统计筛选组合测试
- CSV 导出表头与数据行测试
- 批阅状态判定测试

### 前端

- 老师考试页筛选、重置、导出测试
- 批阅工作台待批阅过滤、跳题与进度显示测试
- 学生考试页刷新恢复、保存失败、交卷失败重试测试

## 交付标准

满足以下条件视为本轮完成：

1. 老师可以按状态/批阅状态/姓名学号筛选成绩列表。
2. 老师可以导出当前筛选结果 CSV。
3. 老师可以在答卷内连续完成主观题批阅，不必反复回列表定位题目。
4. 学生刷新页面后可恢复未完成考试。
5. 保存失败与交卷失败均可重试且不丢当前上下文。
