# 测试计划与验收标准

## 1. 测试目标
确保项目满足：功能完整、业务规则正确、多租户隔离正确、权限边界正确、历史快照可追溯、页面可用、导入可用、统计可信。

## 2. 测试范围
### 2.1 功能测试
- 登录认证
- 租户/组织/班级/课程/师生关系
- 角色权限/菜单权限
- 公告通知
- 题库/题目/标签/评论/质疑
- 导入模板下载与导入
- 练题
- 考试
- 数据看板
- 快照历史

### 2.2 非功能测试
- 性能
- 安全
- 兼容性
- 可用性
- 日志与可观测性

## 3. 验收标准（关键模块）
### 3.1 多租户与权限
1. 系统管理员可查看全部租户数据。
2. 租户管理员不可读取其他租户数据。
3. 老师只能访问自己负责班级/课程或被授权题库的数据。
4. 学生只能访问自身可见题库、考试和个人记录。
5. 菜单隐藏与接口权限都必须生效。

### 3.2 题库与题目
1. 支持单选、多选、判断题。
2. 选择题选项数量不固定。
3. 题干/选项支持图片和文本混合。
4. 题库可与课程关联，也可独立存在。
5. 题库可向下级下发，且下级默认不能直接修改上级原题。
6. 标签支持系统标签筛选与个人标签沉淀。
7. 评论与质疑流程可闭环。

### 3.3 练题
1. 支持顺序/随机练题。
2. 支持单题库/多题库练题。
3. 错题、熟题、疑惑题记录正确。
4. 熟题过滤只在练题生效，不在考试生效。
5. 练题记录可追溯到会话与题目级别。

### 3.4 考试
1. 仅老师及以上层级可创建考试。
2. 支持按题型、分值、总分、知识点规则随机组卷。
3. 题量不足时阻止发布并给出缺口说明。
4. 考试按时间限制进行，自动交卷有效。
5. 客观题自动判分结果准确。
6. 错题可从考试沉淀，但不应产生熟题标记。

### 3.5 快照与历史
1. 学生转班、升级、毕业、离校产生历史记录。
2. 教师任课变更可追溯。
3. 历史统计可基于快照回放，不因当前组织关系变化而失真。

### 3.6 导入
1. 模板可下载。
2. 合法模板可成功导入。
3. 非法模板返回明确错误行与原因。
4. 图片/JSON 字段格式错误要有清晰提示。

## 4. 性能建议标准
- 常规列表接口 P95 ≤ 500ms
- 题目详情接口 P95 ≤ 300ms
- 组卷预检查在中等数据量下（如 1 万题）响应时间可控在 3s 内
- 导入 1000 行模板时应有明确进度与结果反馈

## 5. 上线前退出标准
- P0 = 0
- P1 = 0
- 关键验收项全部通过
- 验收清单通过率达到预设阈值
- 已完成回滚预案与上线 smoke test
