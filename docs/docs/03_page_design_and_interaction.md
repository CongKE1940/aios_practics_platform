# 页面设计与交互说明

## 1. 页面设计原则
1. 一页面一功能优先，不在单页塞入过多互不相关内容。
2. 所有主内容区域最大宽度建议 1200px~1440px，并居中显示。
3. 表单页优先使用窄版布局（建议主体宽度 720px~960px），减少横向分散。
4. 卡片、筛选区、表格、按钮之间必须有显式间距：模块间距 24px，组件间距 16px，按钮与相邻文字 8px~12px。
5. 空态、加载态、错误态必须设计，不可只设计正常态。
6. 重要操作区始终固定在用户视觉主路径上：标题区 → 筛选区 → 主内容 → 操作区。

## 4. 关键页面详细说明
### 4.1 A-09 题库管理页
- 顶部：页面标题 + “创建题库”主按钮
- 第二行：筛选区（课程、归属层级、状态、标签）
- 主体：题库表格
- 右侧操作：详情、下发、查看题目、导出
- 空态：展示“暂无题库，先创建一个题库”
- 无权限态：解释当前角色为何无权创建/下发
- 下发失败态：展示题量、范围或权限原因

### 4.2 A-11 题目编辑器
1. 左侧：基础信息（题型、课程、标签、难度）
2. 中间：题干编辑区
3. 选项编辑区：动态增删选项，不限制 4 个
4. 答案区：按 option key 选择正确答案，判断题显示对/错
5. 解析区
6. 右侧：实时预览

交互规则：
- 增加选项后自动生成稳定 key（A/B/C…，超过 26 个则 AA/AB…）。
- 拖拽排序只改变显示顺序，不改变 option key。
- 当题干和选项都为图片时，仍用 option key 表示答案。
- 保存前需校验：题干非空、答案合法、图片资源可访问。

### 4.3 U-06 练题页
- 顶部：题库来源、进度、退出按钮
- 中部主卡片：题干 + 选项
- 右侧/底部：答题卡（可选）
- 底部操作栏：上一题、提交答案、下一题、标熟、标疑惑、评论、质疑

行为规则：
- 客观题提交后立即判断对错；
- 正确后允许标记熟题；
- 错误自动进入错题记录；
- 疑惑可在未提交前后都标记；
- 若启用“排除熟题”，请求下一题时过滤 mastered_flag=1。

### 4.4 A-14 / U-17 随机组卷页
- 左侧：组卷规则表单
- 右侧：题量匹配概览与风险提示
- 底部：生成预览、保存模板、立即发布

关键交互：
- 输入每种题型数量和分值
- 选择知识点范围
- 可设置“每个知识点每种题型数量”
- 实时校验题量缺口
- 预览试卷摘要（不暴露具体题目给无权限用户）

### 4.5 U-14 考试作答页
- 顶部：考试名、倒计时、答题进度
- 左侧：题目区
- 右侧：答题卡 + 提交按钮
- 底部：上一题/下一题

强规则：
- 考试中不显示“熟题/疑惑题”按钮；
- 允许自动保存作答进度；
- 时间结束自动交卷；
- 刷新页面可恢复剩余时间与已作答状态。

## 5. 页面级状态设计
每个页面都至少需要四种 UI 状态：Loading、Empty、Error、No Permission。

## 6. 设计语言建议
- 管理端：浅色背景 + 白色卡片 + 强层级标题。
- 用户端：更聚焦任务型布局，减少后台感。
- 字体：中文优先系统字体，字号 14/16/20 三层级。
- 卡片圆角：8~12px。
- 阴影：轻量级，不要厚重。
- 图表：克制使用，优先服务信息表达而非装饰。

## 7. 响应式预留
- 一期桌面端断点：1280 / 1440 / 1600。
- 平板预留：主内容单列化、筛选区折叠抽屉。
- 手机预留：页面拆分更细，操作区固定底部，保持领域层复用。
