## 2. 已落实的业务口径

1. 练题记录默认按会话展示。
2. 会话详情展示用户答案、正确答案、解析和题目状态。
3. 错题本、熟题本、疑惑题复用用户题目状态能力。
4. 状态列表可以从当前筛选结果继续练。
5. 从列表继续练会创建新会话并进入练题页。
6. 所有练题记录、结果详情和题目状态均按 `tenant_id + user_id` 隔离。
7. 老师侧学习页、复杂统计、知识点算法、评论质疑和考试联动不进入阶段 2D。

## 3. 当前限制

2. 后端列表分页当前保留已有仓库风格，后续数据量上来后建议下推 SQL 分页。
3. 暂无老师查看学生练题情况。
4. 暂无知识点掌握度算法。
5. 暂无评论、质疑和考试错题联动。
