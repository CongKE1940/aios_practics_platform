# 项目里程碑与交付计划

## 总体建议周期
按 5 个阶段推进，可按 8~12 周组织，但具体以团队规模为准。

## 阶段 0：需求冻结与架构确认
交付物：PRD、业务架构、页面清单、API 草案、数据库草案。

## 阶段 1：基础平台能力
范围：登录认证、多租户上下文、用户/角色/菜单/权限、学校/年级/班级/课程基础管理、公告/通知。

## 阶段 2：题库与导入
范围：题库管理、题目编辑器、标签/评论、题库下发、模板下载与导入、题目质疑初版。

## 阶段 3：练题闭环
范围：题库选择、练题配置、顺序/随机练题、错题/熟题/疑惑题、练题结果页。

## 阶段 4：考试闭环与数据分析
范围：随机组卷、发布考试、考试作答与自动判分、成绩统计、管理端考试与学习数据看板。

## 阶段 5：快照、优化与上线
范围：升级/升学/毕业/离校快照、教师任课历史、质疑处理完善、性能优化、上线准备与回滚预案。
