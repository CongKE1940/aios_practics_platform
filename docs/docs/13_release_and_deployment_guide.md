# 发布、部署与上线说明

## 1. 环境建议
- dev：开发环境
- test：测试环境
- staging：预发布环境
- prod：生产环境

## 2. 组件建议
- Nginx
- admin-web
- user-web
- api-server
- mysql8
- redis
- minio（或 S3 兼容对象存储）

## 3. 配置管理
按环境管理以下配置：数据库连接、Redis 连接、JWT 密钥、对象存储配置、CORS 域名白名单、日志等级。

## 4. 发布流程
1. 代码合并到主分支
2. 运行单元测试、lint、构建
3. 部署到 staging
4. 执行 smoke test
5. 数据 migration
6. 发布 prod
7. 观察指标与日志

## 5. Smoke Test 建议
- 登录可用
- 首页可用
- 题库列表可打开
- 练题可进入并提交
- 考试列表可打开
- 导入模板可下载
- 通知可查看

## 6. 回滚预案
- 前端版本回退到前一个稳定镜像
- 后端镜像回退到前一个稳定版本
- 数据库 migration 必须支持向前兼容，涉及破坏性变更时先双写或灰度
