# 阶段 2G 考试主链路状态

更新时间：2026-04-23

## 已完成

- 新增后端考试模块，覆盖考试草稿创建、更新、发布、固定试卷、随机组卷、学生开考、答题保存、交卷判分、结果查询。
- 学生 `GET /api/v1/exams` 可查询自己可参加的已发布考试；老师仍可通过 `exam:publish` 查看租户内考试管理列表。
- 开考与 attempt 查询返回题目 `question_type` 和 `content`，学生端可渲染题干与选项。
- SDK 已补齐考试管理、开考、答题保存、交卷、结果查询契约。
- 用户端已接入老师考试管理页，支持考试列表、固定试卷草稿、随机组卷草稿、发布。
- 用户端老师考试管理页已补充考试详情查看、草稿回填编辑、固定试卷预览、随机组卷规则预览。
- 用户端老师考试管理页已补充考试统计与成绩查看，支持应参加人数、参与/交卷/未开始人数、均分/最高分/最低分以及学生成绩列表。
- 用户端老师考试管理页已补充成绩明细筛选与当前筛选结果 CSV 导出，支持按作答状态、批阅状态、学生姓名/学号筛选。
- 用户端老师考试管理页已补充单个学生答卷明细与按题查看，支持从成绩列表进入答卷、按题切换查看题干、学生答案、正确答案、判题结果和得分。
- 用户端老师考试管理页已补充主观题批阅与老师补评分，支持对 `short_answer`、`essay` 录入分数和评语，并实时回写答卷总分。
- 用户端老师考试管理页已补充批阅工作台增强，支持自动定位首个待批阅主观题、仅看待批阅、批阅进度、上一题/下一题连续批阅。
- 用户端已接入学生考试入口与作答页，支持查看可参加考试、开始考试、保存答案、交卷并查看得分。
- 学生作答页已补充倒计时、到时自动交卷、题号导航、交卷二次确认、刷新/关闭提醒。
- 学生作答页已补充异常恢复，支持本地恢复最近一次未完成考试、保存失败重试、交卷失败重试且不丢当前上下文。
- 老师考试页已补充异常恢复，支持统计加载失败保留当前详情、答卷切换失败不覆盖已打开答卷、批阅保存失败保留当前输入。
- 用户菜单已补齐真实考试入口：老师显示“考试管理”，学生显示“考试入口”。
- 正式 `docs/api/openapi.yaml` 已为考试列表、考试详情、开考、作答保存、交卷、结果查询收口强类型 response schema。
- 正式 `docs/api/openapi.yaml` 已补齐 `GET /api/v1/analytics/exam-overview` 强类型 response schema。
- 正式 `docs/api/openapi.yaml` 已补齐 `GET /api/v1/analytics/exam-overview-export` 契约，并为考试概览补充筛选 query 与批阅状态字段。
- 正式 `docs/api/openapi.yaml` 已补齐 `GET /api/v1/analytics/exam-attempt-review` 强类型 response schema。
- 正式 `docs/api/openapi.yaml` 已补齐 `PUT /api/v1/analytics/exam-attempt-question-review` 强类型 request / response schema。
- 考试交卷流程已支持主观题进入待人工批阅状态，老师补评分后可回写批语、批阅人和批阅时间。
